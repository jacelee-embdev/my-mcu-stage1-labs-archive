# STM32 语音控制小车框架

## 项目简介

本实验用于读取语音识别模块的三路数字输出，并为语音切换循迹、跟随和避障模式搭建小车控制框架。语音输入连接 PA2、PA1、PA0，可组成多个三位状态码。

## 当前状态

主循环目前每秒读取一次语音引脚，并通过串口打印 `001`、`010`、`011`、`100`、`101` 或 `110` 等识别码。工程中已经包含循迹、红外跟随以及舵机配合超声波扫描避障的辅助函数，但这些函数尚未在主循环中与具体语音码绑定。

因此，当前版本是语音码验证与多模式集成框架，还不是已经完成的语音驾驶程序。

## 使用方法

打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载，先确认各语音码输出稳定，再在 `Users/main.c` 中建立命令与动作/模式的映射。联调电机前应加入默认停止和失联保护。

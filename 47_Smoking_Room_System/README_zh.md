# STM32F103C8T6 吸烟室管控系统

## 项目简介

本工程使用模拟烟雾传感器监测吸烟室空气状态。ADC1 通道 8 通过 DMA 持续采集 PB0 电压，LCD1602 同时显示当前烟雾值和报警阈值；超过阈值时自动开启风扇继电器并鸣响蜂鸣器。

## 主要功能

- 连续采集 PB0/ADC1_IN8 的烟雾传感器电压。
- 两个按键以 0.1 V 步进降低或提高阈值，初始值为 1.0 V。
- LCD1602 显示实时值和设定值。
- 超限时启动排风扇和蜂鸣器，恢复正常后自动关闭。

## 硬件说明

阈值按键使用 PB13/PB14。传感器、LCD、蜂鸣器和继电器的其余引脚见对应 BSP 驱动。实际烟雾浓度需要根据传感器型号重新标定，当前电压阈值仅用于实验。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，先以低压负载验证逻辑，再连接风扇模块。

## 主要文件

- `Drivers/BSP/adc/`：烟雾电压采集。
- `Users/main.c`：阈值、显示和联动控制。

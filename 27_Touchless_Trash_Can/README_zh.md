# STM32F103C8T6 感应垃圾桶

## 项目简介

本工程组合 HC-SR04、SG90 舵机、按键、蜂鸣器和 LED，实现简易感应开盖垃圾桶。按下按键 1，或超声波检测到目标距离小于 10 cm 时，舵机打开桶盖并保持约 2 秒；无触发条件时自动关盖。

## 主要功能

- 使用 HC-SR04 判断是否有人靠近。
- 支持按键手动触发开盖。
- SG90 在 0° 与 180° 之间控制桶盖。
- 开盖时短鸣蜂鸣器，并用两路 LED 指示开关状态。
- 通过状态标志避免重复执行开盖提示。

## 硬件说明

工程涉及舵机和超声波模块，需保证电源容量、共地和 ECHO 电平匹配。具体引脚以各 BSP 驱动头文件为准。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接模块并确认舵机机械角度后编译下载。

## 主要文件

- `Drivers/BSP/trash_bin_ctrl_core/`：开盖、关盖和状态逻辑。
- `Drivers/BSP/hcsr04/`、`pwm_sg90/`：测距和舵机驱动。

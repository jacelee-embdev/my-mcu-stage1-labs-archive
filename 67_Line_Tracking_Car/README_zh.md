# STM32 双路循迹小车

## 项目简介

本实验使用左右两个红外循迹传感器判断地面轨迹，并通过两轮电机的方向组合完成简单循线。PB13 接左传感器，PB14 接右传感器；当前驱动把低电平视为检测有效。

## 控制逻辑

- 两路都有效：小车前进。
- 仅右侧有效：向左修正。
- 仅左侧有效：向右修正。
- 两路都无效：停止。

主循环约每 10 ms 读取一次传感器。本版本采用固定速度和开关式修正，适合验证传感器极性及基本循迹逻辑。

## 使用方法

调整传感器高度和灵敏度，使其能稳定区分轨迹与背景。打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。若左右修正方向相反，请检查传感器位置、电机接线和有效电平定义。

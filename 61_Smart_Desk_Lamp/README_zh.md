# STM32 智能台灯

## 项目简介

本实验把灯光、人体检测、光照检测、超声波测距、蜂鸣器、OLED、按键和蓝牙控制组合成一个智能台灯原型。系统可根据环境和人员状态自动调光，也可通过按键或串口蓝牙进行人工控制。

## 主要功能

- 自动、手动和远程三种灯光模式。
- 自动模式根据人体存在和光照强弱选择亮度。
- HC-SR04 检测坐姿距离，距离过近时蜂鸣提醒。
- 记录连续使用时间，并支持启动、停止和复位。
- OLED 显示距离、计时和当前状态。

## 使用说明

接好灯光 PWM、传感器、OLED、按键和蓝牙模块后，打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。光照阈值、距离阈值和提醒时间均为实验参数，应根据实际传感器安装位置重新标定。

## 主要代码

- `Users/main.c`：模式切换和总体控制。
- `Drivers/BSP/`：灯光、蓝牙、测距、光照、人体检测及显示驱动。

# STM32 小车 PWM 调速

## 项目简介

本实验使用 TIM2 的两个 PWM 通道分别控制左右电机的使能端，从而验证两轮小车的独立调速和差速转向。方向引脚决定电机转向，PWM 占空比决定有效驱动力。

## 运行效果

定时器产生约 50 kHz PWM。程序循环设置三组左右轮比较值：左慢右快、左快右慢和两轮同速，每组保持约 1 秒，可直观看到差速对行驶轨迹的影响。

## 硬件说明

TIM2_CH1（PA0）控制左轮 PWM，TIM2_CH2（PA1）控制右轮 PWM。PWM 应接电机驱动模块的速度/使能输入，不能直接连接电机。电机电源与控制电源应合理隔离并共地。

## 使用方法

打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。根据电机、驱动板和车体负载调整 PWM 频率及比较值，并先架空车轮确认调速范围。

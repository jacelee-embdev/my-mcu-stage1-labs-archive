# MPU6050 连续读写

## 项目简介

本实验在 GPIO 模拟 I2C 的单寄存器操作基础上，实现 MPU6050 连续寄存器的突发读写。通过一次寻址连续传输多个字节，可减少重复起停条件，为后续一次读取完整传感器数据和加载 DMP 数据打基础。

## 测试内容

- 配置 MPU6050 时钟、100 Hz 采样率、低通滤波和量程。
- 读取 `WHO_AM_I` 并检查设备 ID。
- 从采样率分频寄存器开始连续写入 4 字节。
- 连续读回 4 字节并通过串口显示，比较首字节判断通信结果。

测试完成后，主循环每秒翻转 LED。

## 使用方法

接好 MPU6050 并确认 SCL/SDA 上拉，打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。用 115200 波特率查看诊断信息。测试会改写一段配置寄存器，只用于学习验证；正式采集前应重新执行正确的初始化配置。

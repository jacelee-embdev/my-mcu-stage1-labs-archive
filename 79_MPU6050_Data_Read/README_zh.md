# MPU6050 六轴原始数据读取

## 项目简介

本实验使用 GPIO 模拟 I2C，从 MPU6050 的加速度 X 轴高字节寄存器开始连续读取 14 字节，并组合得到三轴加速度、原始温度以及三轴陀螺仪数据。它展示了连续读取和高低字节拼接的完整过程。

## 运行效果

MPU6050 被配置为 100 Hz 采样率、5 Hz 数字低通滤波、陀螺仪 ±2000 dps 和加速度计 ±16 g。主循环约每秒读取一次全部原始值，通过 115200 波特率串口打印，同时翻转 LED。

当前输出是传感器寄存器的有符号原始计数，温度、加速度和角速度尚未换算为物理单位，也未进行零偏校准。

## 使用方法

打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。静止放置模块观察零点和噪声；需要物理量时，再依据当前量程灵敏度加入换算、偏置和滤波处理。

# STM32 TB6612 双电机驱动

## 项目简介

本实验封装了适用于 TB6612 一类双 H 桥模块的两路直流电机驱动。PB12–PB15 控制左右电机方向，TIM1_CH1（PA8）和 TIM1_CH4（PA11）输出 PWM。`motor_set_speed()` 使用参数正负号选择方向、绝对值设置速度，零值执行停止。

## 当前运行状态

驱动中提供了完整测试序列，可分别验证左右电机正反转、多档速度、同步运动、原地转向和差速转弯。但当前 `main.c` 中的 `motor_test_sequence()` 被注释，因此下载后只完成初始化，不会主动驱动电机。

## 使用方法

确认 TB6612 电源、待机/使能、方向和 PWM 接线后，按需取消测试函数注释。打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。首次测试必须架空车轮、限制电源电流，并准备立即断电；比较值范围与 ARR=7199 对应。

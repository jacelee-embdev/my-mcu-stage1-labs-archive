# STM32F103C8T6 4×4 矩阵键盘

## 项目简介

本工程驱动 4×4 矩阵键盘。空闲时四行配置为下降沿中断输入、四列输出低电平；按键触发后临时反转 GPIO 方向并扫描列位置，通过键值表得到 `0–9`、`A–D`、`*`、`#`。

## 主要功能

- 使用外部中断检测任意一行按键事件。
- 进行 10 ms 软件消抖和行列扫描。
- 将键值保存到单字节缓冲区，由主循环读取并清除。
- 串口打印按下字符，LED1 短暂点亮提示。

## 硬件连接

行线使用 PB0、PB1、PB2、PB10；列线使用 PB11、PB12、PB13、PB14。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，按行列顺序连接键盘后编译下载。

## 主要文件

- `Drivers/BSP/keyboard/keyboard.c`：中断、扫描和键值映射。
- `Users/main.c`：键值读取与打印。

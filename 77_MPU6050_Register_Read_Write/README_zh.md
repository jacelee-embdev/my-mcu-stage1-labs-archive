# MPU6050 单寄存器读写

## 项目简介

本实验使用 STM32F103C8T6 GPIO 模拟 I2C，学习 MPU6050 的基本总线时序和单寄存器读写。驱动手动实现起始、停止、字节发送、字节接收以及 ACK/NACK 处理，没有直接依赖硬件 I2C 外设。

## 测试内容

- 发送器件地址并打印 MPU6050 应答状态。
- 读取 `WHO_AM_I` 寄存器，正常设备 ID 通常为 `0x68`。
- 写寄存器唤醒芯片。
- 向采样率分频寄存器写入测试值，再读回并通过串口打印。

程序完成一次通信测试后，LED 每秒翻转，作为主循环运行指示。

## 使用方法

连接 MPU6050 的 SCL、SDA、电源和地，并确认总线有合适的上拉。打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载，用 115200 波特率查看串口结果。若无应答，优先检查地址、接线和上拉电阻。

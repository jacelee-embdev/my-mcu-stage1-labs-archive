# STM32F103C8T6 LCD1602 字符串显示

## 项目简介

本工程在单字符驱动基础上增加 LCD1602 字符串显示接口。LCD 使用 8 位并行总线，程序初始化显示屏后，分别从两行的指定列开始写入测试字符串，用于验证连续字符输出和行列定位。

## 主要功能

- 完成 LCD1602 指令、数据和上电时序驱动。
- 提供按行列显示单字符及字符串的接口。
- 第一行显示 `LiZhiQiu`，第二行显示 `Handsom`。

## 硬件连接

| LCD1602 信号 | STM32 引脚 |
|---|---|
| D0–D7 | PA0–PA7 |
| RS / RW / EN | PB1 / PB2 / PB10 |

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，按接口定义接好 LCD1602 后编译下载。需要修改显示内容时，调整 `main.c` 中传入的行、列和字符串。

## 主要文件

- `Drivers/BSP/lcd1602/`：LCD1602 并行驱动。
- `Users/main.c`：双行字符串显示示例。

# STM32F103C8T6 蓝牙继电器插座

## 项目简介

本工程使用串口蓝牙模块远程控制继电器插座。USART2 接收不定长命令，并在 IDLE 中断后检查字符串：包含 `ON` 时吸合继电器，包含 `OFF` 时释放继电器。

## 主要功能

- USART2 以 115200 波特率接收蓝牙命令。
- RXNE 中断缓存字节，IDLE 中断判断命令结束。
- PB6 输出低电平时继电器吸合。
- USART1 同步打印收到的蓝牙内容，方便调试。

## 硬件与安全

蓝牙模块连接 PA2/PA3，继电器控制端连接 PB6。若继电器控制市电插座，必须使用具有隔离和保护的合格模块，并在断电状态下接线。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接低压测试负载后编译下载，从蓝牙终端发送 `ON` 或 `OFF`。

## 主要文件

- `Drivers/BSP/bluetooth/`：命令接收与解析。
- `Drivers/BSP/relay_plugin/`：继电器驱动。

# STM32F103ZET6 智能家居 NB 集成版

## 项目简介

本工程是在 ZET6 智能家居基础上的进一步集成版本，包含矩阵键盘密码输入、OLED 界面、W25Q128 密码保存、灯光调节、燃气报警、风扇和门锁控制、蓝牙/语音命令、DHT11 采集以及 ESP8266 MQTT 联网。

## 主要功能

- 启动时初始化各外设并连接 MQTT 平台。
- 键盘输入密码，支持确认以及旧密码校验后的修改流程。
- 定时任务处理自动感光、燃气报警和温湿度上报。
- 蓝牙或语音命令控制灯光、风扇和门锁。

当前工程名称中的 `NB` 用于区分这一版归档；实际联网代码使用的是 ESP8266 和 MQTT。

## 使用说明

该工程外设较多，建议按电源、串口、传感器、执行器、联网的顺序分模块联调。打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载；联网测试前需要填写个人 Wi-Fi、MQTT 和 OneNET 设备参数。

# STM32F103C8T6 智能门禁系统

## 项目简介

本工程组合矩阵键盘、OLED、W25Q128、继电器锁和蜂鸣器，实现密码门禁原型。首次运行时在 Flash 中设置密码；之后输入密码并按 `#` 提交，验证成功后短暂开启门锁，输入错误则提示并累计错误次数。

## 主要功能

- 通过 4×4 键盘输入密码，OLED 显示交互提示。
- 将最多 10 字节密码保存在 W25Q128 第 0 扇区。
- `#` 提交开锁验证，`*` 进入旧密码验证和修改流程。
- 正确时控制继电器锁和蜂鸣器；连续错误达到 3 次时报警。

## 运行说明

这是学习用原型，源码中的密码比较、明文存储和错误处理尚未进行安全审计，不应直接用于真实门禁。重新写入第 0 扇区会覆盖该区域原有数据。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，先使用低压负载验证继电器动作，再连接门锁执行器。

## 主要文件

- `Drivers/BSP/password/`：密码录入、存储和验证流程。
- `Drivers/BSP/keyboard/`、`oled/`、`relay_lock/`、`w25q128/`：外设驱动。

# STM32F103ZET6 智能家居集成实验

## 项目简介

本工程是基于 STM32F103ZET6 的智能家居综合练习，汇集了矩阵键盘、OLED、蜂鸣器、继电器门锁和风扇、W25Q128、ADC、蓝牙、语音、DHT11、ESP8266 与 OneNET/MQTT 等模块。代码中包含密码管理、自动灯光、燃气报警和温湿度上传等功能组件。

## 当前运行状态

当前 `main.c` 初始化大部分外设并执行一次密码检查，主循环实际启用的是 `w25q128_test()`，每 500 ms 读取并打印 Flash 设备 ID。灯光、燃气、数据上传和键盘改密流程仍保留在代码中，但目前被注释，属于待联调的集成功能。

## 使用说明

打开 `Projects/MDK-ARM` 中的 Keil 工程，按需逐项启用功能并单独验证硬件。不要一次接入所有负载后直接运行；启用联网功能时，需要填写与个人网络和 OneNET 设备相匹配的参数。

## 主要代码

- `Users/main.c`：系统初始化与当前测试入口。
- `Drivers/BSP/tasks/`：灯光、报警和数据上传任务。
- `Drivers/BSP/password/`、`w25q128/`：密码与外部 Flash。

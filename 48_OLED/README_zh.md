# STM32F103C8T6 OLED 显示实验

## 项目简介

本工程实现 128×64 OLED 的软件 I²C 驱动，并集中演示英文、数字、标点、中文点阵和位图显示。测试结束后播放开机动画，再进入一个模拟桌面界面，显示时间、CPU 负载、进度条和温度等示例数据。

## 主要功能

- PB6/PB7 模拟 I²C 的 SCL/SDA 时序。
- 支持清屏、坐标定位、字符、字符串、中文和图片显示。
- 包含反色、Logo、启动进度条等开机动画。
- 周期刷新桌面布局和模拟状态数据。

## 运行说明

当前桌面中的时间、负载和温度是演示变量，不是传感器或系统的真实测量值。字库和图片数据位于驱动资源文件中。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接兼容 OLED 后编译下载。

## 主要文件

- `Drivers/BSP/oled/`：OLED 与软件 I²C 驱动。
- `Drivers/BSP/boot_animation/`：动画和桌面界面。

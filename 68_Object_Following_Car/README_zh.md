# STM32 红外跟随小车

## 项目简介

本实验使用安装在车头左右两侧的红外检测模块实现简单目标跟随。STM32F103C8T6 读取 PB5 和 PB6 的传感器状态，根据目标偏向控制左右电机，使小车前进或转向。

## 控制逻辑

- 两路都检测到目标：前进。
- 仅右侧检测到：向右转。
- 仅左侧检测到：向左转。
- 两路都未检测到：停止。

传感器驱动把低电平视为有效，并通过调试串口打印左右状态。该方法不测量实际距离，只适合近距离、反射条件较稳定的演示。

## 使用方法

对称安装传感器并调节灵敏度，打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。若跟随方向错误，请检查左右传感器标识、电机方向和模块输出极性。

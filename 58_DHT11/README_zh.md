# STM32F103C8T6 DHT11 温湿度实验

## 项目简介

本工程使用单总线时序读取 DHT11 温湿度传感器。PA5 在输出和输入模式之间切换，MCU 发送起始信号后读取 40 位数据，并通过校验和确认结果有效。

## 主要功能

- PA5 作为 DHT11 双向数据引脚。
- 使用微秒延时区分数据位 0 和 1。
- 读取湿度整数/小数、温度整数/小数及校验字节。
- 校验成功后通过 USART1 输出温度和相对湿度。
- 两路 LED 交替闪烁作为运行指示。

## 运行说明

DHT11 刷新速度较慢，程序约每秒读取一次。数据线通常需要上拉，供电和逻辑电平应符合模块规格。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接 DHT11 后编译下载并查看串口。

## 主要文件

- `Drivers/BSP/dht11/`：起始时序、位读取和校验。
- `Users/main.c`：周期采集。

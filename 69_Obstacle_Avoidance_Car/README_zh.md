# STM32 超声波避障小车

## 项目简介

本实验组合 HC-SR04 超声波模块、舵机和两轮电机，演示小车在前方受阻时扫描左右空间并选择较空方向。舵机依次转向左、中、右位置，超声波模块在各方向测距。

## 当前流程

程序读取前方距离后停止电机，测量左侧和右侧距离，再朝距离较大的一侧短暂转向约 200 ms，最后停止并让舵机回中。距离值会通过调试串口输出。

需要注意：当前主循环没有持续前进逻辑，因此它更准确地说是“扫描并选择转向”的避障步骤实验，而不是完整的自主巡航程序。

## 使用方法

打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。先校准舵机角度和超声波测距，再架空车轮验证转向；若要连续避障，需要补充前进条件和安全距离判断。

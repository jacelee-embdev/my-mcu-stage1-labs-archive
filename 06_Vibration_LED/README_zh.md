# STM32F103C8T6 振动点灯实验

## 项目简介

本工程使用振动传感器触发 LED，演示外部中断与事件标志位的配合。传感器信号接入 PA4，检测到下降沿后只在中断中设置标志，主循环读取标志并执行较长时间的点灯动作。

## 主要功能

- 将 PA4 配置为 EXTI4 下降沿中断输入。
- 通过标志位把传感器事件从中断传递到主循环。
- 检测到振动后点亮 PB8 上的 LED 约 2 秒。

## 硬件与现象

| 模块 | 引脚 / 配置 |
|---|---|
| 振动传感器 | PA4，低电平触发 |
| 指示 LED | PB8，低电平点亮 |

振动传感器被触发时，LED 点亮 2 秒后自动熄灭。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接传感器后编译下载。

## 主要文件

- `Users/main.c`：事件处理和延时点灯。
- `Drivers/BSP/EXTI/`：振动检测中断与标志位。

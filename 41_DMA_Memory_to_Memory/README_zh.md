# STM32F103C8T6 DMA 内存到内存

## 项目简介

本工程演示 DMA1 通道 1 的内存到内存搬运。源缓冲区包含 16 个递增规律的 32 位测试值，DMA 按字节把整段数据复制到目标缓冲区，完成后通过 USART1 打印目标内容进行校验。

## 主要功能

- 配置 DMA1_Channel1 为 `MEMORY_TO_MEMORY`。
- 源地址和目标地址均开启自动递增。
- 使用普通模式完成一次 64 字节传输。
- 轮询传输完成标志，并打印 16 个目标数据。

## 运行现象

串口先输出目标缓冲区内容，数值应与源数组一致；之后两路 LED 持续交替闪烁。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，编译下载后在 115200 波特率终端查看复制结果。

## 主要文件

- `Drivers/BSP/dma/dma.c`：DMA 配置、源/目标数组和结果打印。
- `Users/main.c`：启动传输。

# STM32F103C8T6 红外传感器实验

## 项目简介

本工程演示数字式红外传感器的外部中断检测。传感器输出接入 PB4，出现低电平下降沿时由 EXTI4 记录事件，主循环读取标志后点亮 LED1 两秒。

## 主要功能

- 将 PB4 配置为上拉、下降沿触发的外部中断输入。
- 使用事件标志将中断检测和主循环处理分离。
- 红外事件发生后点亮 PB8 指示 LED 约 2 秒。

## 硬件与现象

| 模块 | 引脚 / 配置 |
|---|---|
| 红外传感器数字输出 | PB4，低电平触发 |
| 指示 LED | PB8 |

传感器检测到目标并输出有效信号后，LED 短暂点亮再自动熄灭。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接传感器后编译下载。若模块输出极性不同，需要调整中断边沿和有效电平判断。

## 主要文件

- `Users/main.c`：红外事件处理。
- `Drivers/BSP/EXTI/`：传感器中断驱动。

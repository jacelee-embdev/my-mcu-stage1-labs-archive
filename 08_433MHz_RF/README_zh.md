# STM32F103C8T6 433 MHz 无线接收实验

## 项目简介

本工程读取 433 MHz 无线接收模块的两路数字输出，用于识别遥控器 A、B 两个按键。PA5 和 PA12 均采用上升沿外部中断，触发后设置对应标志，主循环再翻转两路 LED。

## 主要功能

- 配置 PA5 和 PA12 两路 EXTI 输入。
- 分别保存遥控器 A、B 键的触发标志。
- A 键翻转 LED1，B 键翻转 LED2。

## 硬件与现象

| 模块 | 引脚 |
|---|---|
| 433 MHz A / B 信号 | PA5 / PA12 |
| LED1 / LED2 | PB8 / PB9 |

接收模块识别到对应遥控按键后，相应 LED 的状态改变一次。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，将已配对接收模块的数字输出连接到指定引脚，再编译下载。

## 主要文件

- `Users/main.c`：无线按键事件处理。
- `Drivers/BSP/EXTI/`：接收输入中断与标志位。

# STM32 点动控制小车

## 项目简介

本实验实现小车的“点动”控制：每收到一次串口命令，只执行约 200 ms 的短距离动作，随后主循环立即让电机停止。与持续遥控相比，这种方式更适合观察单步动作和进行小范围位置调整。

## 控制命令

- `M1`：短暂前进。
- `M2`：短暂后退。
- `M3`：短暂左转。
- `M4`：短暂右转。
- 其他内容：停止。

命令通过 USART2 在接收空闲中断中解析，当前中断处理内包含 200 ms 延时，仅适合作为学习实验。

## 使用方法

接好串口或蓝牙透传模块及电机驱动，打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载。可调整延时时间改变每次点动距离；正式项目不建议在中断中进行长时间阻塞。

# STM32F103C8T6 BKP 备份寄存器读写

## 项目简介

本工程演示 STM32F103 的备份域访问。程序开启 PWR 和 BKP 时钟、解除备份域写保护，然后向 RTC 备份寄存器 1 写入 `0xA5A5`，立即读回并通过 USART1 打印。

## 主要功能

- 初始化 RTC 句柄和 32.768 kHz 到 1 Hz 的预分频。
- 使用 HAL 接口读写指定备份寄存器。
- 写入固定标记并校验读回值。
- 主循环交替闪烁两路 LED。

## 运行说明

备份寄存器可在主电源断开后由 VBAT 域保持，前提是硬件提供有效备份电源且未复位备份域。本实验常用于保存“是否已初始化”等少量状态。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，编译下载后在串口终端查看 `A5A5` 读回结果。

## 主要文件

- `Drivers/BSP/rtc/rtc.c`：备份域和寄存器接口。
- `Users/main.c`：写入与读取测试。

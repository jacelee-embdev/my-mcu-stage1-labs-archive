# STM32 小车基本运动

## 项目简介

本实验用于验证两轮直流电机小车的基本方向控制。STM32F103C8T6 通过电机驱动模块分别控制左右电机方向，使小车依次执行前进、后退、左转、右转和停止动作。

## 运行效果

程序循环执行五个动作，每个动作保持约 1 秒。该工程重点是理解左右轮方向组合与整车运动方向之间的关系，也是后续串口遥控、循迹、跟随和避障工程的基础。

## 硬件说明

代码使用 PB0、PB1 控制左电机方向，PB2、PB10 控制右电机方向。必须通过电机驱动板连接电机，不可由 MCU GPIO 直接驱动；电机电源应独立供电并与开发板共地。

## 使用方法

打开 `Projects/MDK-ARM` 中的 Keil 工程，确认方向引脚与接线一致后编译下载。若实际运动方向相反，可交换对应电机线或调整方向控制逻辑。

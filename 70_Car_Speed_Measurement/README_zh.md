# STM32 小车测速

## 项目简介

本实验使用 PB12 的下降沿外部中断统计测速传感器脉冲，同时利用 TIM2 每 100 ms 触发一次处理，将该时间窗内的脉冲数量通过调试串口输出。程序启动后会让小车持续前进。

## 测量原理

传感器每产生一个有效脉冲，计数值加一；定时器回调打印计数并清零。代码中的输出标签为 `speed`，但当前数值本质上是“每 100 ms 的脉冲数”，还不是经过标定的 cm/s 或 m/s。

## 使用方法

接好测速模块和电机驱动，打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载，并用 115200 波特率查看串口。若要换算真实速度，需要结合每圈脉冲数、轮径、减速比和采样周期建立转换公式。

# STM32 PID 两轮平衡车

## 项目简介

本工程把 MPU6050 DMP、双路编码器、双电机 PWM 和蓝牙命令组合成两轮自平衡车控制实验。MPU6050 的数据就绪中断置位后，主循环读取姿态、陀螺仪和编码器数据，再执行多环控制并输出左右电机 PWM。

## 控制结构

- 直立环：使用俯仰角和 Y 轴角速度进行 PD 控制。
- 速度环：使用双轮编码器增量进行 PI 控制并限制积分。
- 转向环：使用蓝牙目标与 Z 轴角速度进行 PD 控制。
- 最终输出进行左右轮混合和 ±7000 限幅。

蓝牙命令可待机、增减目标速度以及左右转向。当前 PID 参数和机械零点是实验初值，不能直接适用于所有车体。

## 安全调试

先固定或悬空车体验证姿态方向、编码器符号和电机方向，再由小到大整定参数。错误方向会使电机瞬间全速输出。打开 `Projects/MDK-ARM` 中的 Keil 工程编译下载，并始终准备断开电机电源。

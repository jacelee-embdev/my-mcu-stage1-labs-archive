# STM32F103C8T6 脉冲计数实验

## 项目简介

本工程把 TIM2 配置为外部时钟模式，用硬件计数器统计 PA1 输入的脉冲。TIM2 通道 2 的下降沿作为计数时钟，主循环读取计数寄存器，并在数值变化时通过 USART1 输出最新结果。

## 主要功能

- 使用 TIM2 外部时钟模式 1，无预分频计数。
- PA1/TIM2_CH2 每出现一次下降沿，计数值加一。
- 计数范围使用 16 位自动重装值 65535。
- 串口仅在计数变化时打印 `CNT`，减少重复输出。

## 运行现象

向 PA1 输入按键脉冲或数字脉冲源后，串口终端会显示递增的计数值。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，连接脉冲源和共地后编译下载。

## 主要文件

- `Drivers/BSP/counter/counter.c`：外部时钟计数和读取逻辑。
- `Users/main.c`：初始化与持续查询。

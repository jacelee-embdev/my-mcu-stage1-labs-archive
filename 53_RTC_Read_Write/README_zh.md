# STM32F103C8T6 RTC 时间读写

## 项目简介

本工程使用 32.768 kHz LSE 为 RTC 提供时钟，演示日期时间的首次设置和持续读取。备份寄存器 1 中的 `0xA5A5` 作为初始化标记，避免每次复位都重新设置 RTC。

## 主要功能

- 配置 LSE、RTC 时钟源和 1 Hz 计数基准。
- 首次运行设置时间为 2026-01-24 21:40:05。
- 使用 BKP 标记判断 RTC 是否已经初始化。
- 主循环读取年月日时分秒并通过 USART1 输出。

## 运行说明

在备份电源有效且备份域未被清除时，RTC 会在复位或主电源断开后继续计时。首次测试前若需要重新设置时间，可清除备份域或修改初始化标记。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，确认板上安装 LSE 晶振后编译下载。

## 主要文件

- `Drivers/BSP/rtc/rtc.c`：RTC、LSE、时间与 BKP 接口。
- `Users/main.c`：首次初始化和时间读取。

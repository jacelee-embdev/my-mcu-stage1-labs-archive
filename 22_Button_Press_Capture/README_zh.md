# STM32F103C8T6 完整按键捕获

## 项目简介

本工程在 TIM2 输入捕获基础上识别一次完整的按键动作。PA1 默认为上拉输入，首次下降沿代表按下，程序随后把捕获极性切换为上升沿等待释放；释放后恢复下降沿，为下一次按键做准备。

## 主要功能

- 使用 TIM2_CH2 捕获 PA1 的电平边沿。
- 在下降沿和上升沿之间动态切换捕获极性。
- 串口分别输出 `DOWN` 和 `UP`，标记按下与释放。
- 主循环保持两路 LED 交替闪烁。

## 运行现象

完成一次按下并释放后，USART1 依次输出按下和释放提示。该实验关注完整边沿序列，尚不计算持续时间。

## 使用方法

使用 Keil MDK 打开 `Projects/MDK-ARM/stm32f103.uvprojx`，将低电平有效按键接到 PA1 后编译下载。

## 主要文件

- `Drivers/BSP/ic/ic.c`：双边沿捕获状态逻辑。
- `Users/main.c`：外设初始化。
